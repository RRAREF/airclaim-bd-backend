# ✈️ AirClaim BD

AirClaim BD is a Lost & Found Management System for airports in Bangladesh.

---

## 🚀 Live Links

### Frontend
https://airclaim-bd-frontend.vercel.app/

### Backend
https://airclaim-bd-backend-production.up.railway.app

---

## 🧠 Features

- User Registration & Login
- Report Lost Items
- Report Found Items
- Automatic Matching System (Bag Tag / Ticket Number)
- Status Tracking (Pending / Matched)

---

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- Bootstrap
- Axios

### Backend
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL (Railway Cloud)

---

## ☁️ Deployment

- Frontend: Vercel
- Backend: Railway
- Database: Railway MySQL

---

## 🔗 API Endpoints

- POST /api/users/signup
- POST /api/users/login
- POST /api/lost-items
- POST /api/found-items
- GET /api/lost-items
- GET /api/found-items
